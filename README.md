# Анализ инфраструктуры велопарковок Москвы
Проект представляет собой цикл обработки данных и аналитики распределения городских велопарковок на основе открытых данных Правительства Москвы(JSON). Главная цель исследования - оценить текущее состояние велосипедной инфраструктуры и найти потенциальные точки роста для развития городской мобильности.

# 🛠 Стек технологий
- **Язык программирования:** Python (Pandas, JSON)
- **Базы данных:** PostgreSQL, SQL
- **Визуализация данных:** MS Excel (интерактивный дашборд)
- **Среда и инструменты:** Jupyter Notebook, Git, VS Code

# 📂 Структура репозитория
- `portfolio_project.ipynb` - основной Jupyter-блокнот с кодом: загрузка сырых данных, очистка, обработка пропусков и экспорт.
- `sql/` — директория с аналитическими SQL-запросами к базе данных.
- `дашборд.xlsx` - сводный дашборд с визуализацией метрик.
- `.env.example` - безопасный шаблон конфигурации для подключения к БД.
- `.gitignore` - системный файл для изоляции локальных ключей и паролей.

#  📊 Ключевые выводы
**Распределение по округам:** Абсолютным лидером по количеству и вместимости велопарковок является ЦАО (более 2500 мест). Новая Москва находится на последнем месте с минимальными показателями, что говорит о дефиците инфраструктуры в новых районах.

**Локализация объектов:** Выявлен сильный дисбаланс: велопарковки активно развиваются у учебных заведений (16%), тогда как у важнейших транспортных узлов - станций метро — их доля мала (всего 1.9%). Это указывает на упущенную точку роста для развития поездок.

**Вместимость парковок:** Более половины всех велопарковок города - это малые велопарковки вместимостью менее 5 мест. Стандартные крупные парковки на 10 мест составляют лишь меньшую часть.

**Лидеры по районам:** В топ-3 районов по обеспеченности вошли Центральный административный округ и Южный административный округ, что связано с общей развитостью инфраструктуры центра города.
